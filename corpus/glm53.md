## 一、结论速览(TL;DR)

1. **推理探针(题 2)是全场最有信息量的一题**:GLM-5.2 API 纯推理路径**手算了完整 26 项递推,一次全对**(f(25)=1,389,537,耗时 120.9s、8055 completion tokens);GLM-5.3 会话路径逐项手算**在 f(17) 处漂移出错**(得 1,352,537),但主动用工具复核并纠正。两代走的是**不同的能力路线**:5.2 靠深思考硬算,5.3 靠"算+验"的工具协作。
2. **题 1(编码)5.3 略优**:两者都给出正确实现,5.3 用 RLock(可重入,更稳)、测试命名与题目要求的 5 个边界逐字对齐;5.2 用普通 Lock、测试覆盖同样 5 个边界(命名不同)。质量同级,5.3 的约束遵循更严格。
3. **题 4(安全审计)5.2 的 CVSS 定级更专业**:5.2 把弱令牌定为 9.8(合理:预认证可利用、可枚举),5.3 定 7.5 偏保守;两者都抓满 7 漏洞+1 笔误,均给出纵深防御补充。
4. **题 5(长上下文)5.2 表现超预期**:5.3 万 token 输入下精确读出 4 个依赖的版本约束差异(caret vs 精确锁定),锁定 simple-icons 为升级风险点并给出 digest-pinning 契约级的理由--但 finish=length 在第 3 问被 8192 max_tokens 截断(长输出截断是魔搭通道默认配置,非模型缺陷)。
5. **"后训练提升"在小样本上的兑现度**:5.3 的增益主要体现为**工具协作意识与约束遵循**(会话形态),纯文本推理质量两代相当甚至 5.2 的深算更稳。这与官方"编码 Agent 基准大涨"一致--增益在 agent 场景,不在纸面解题。

## 三、五题详评

### 题 2 探针:两种能力路线的分野(本场核心发现)

- **GLM-5.2(API)**:reasoning 18182 字符(全文思考 26 项递推),content 878 字符,一次算对。"易错点"回答质量也高:指出"下标从 0 开始,f(25) 是第 26 项,容易错位取 f(24)"--这正是 5.3 会话侧真实犯过的同类错误。
- **GLM-5.3(会话)**:手算链 f(17) 起 +1 漂移,未自察;但具备**工具验证意识**,主动写代码复核并纠正。其"易错点"回答(长链加法累积漂移)恰好自我应验。
- **判读**:这不止是"5.3 会用工具"的轶事--它对应智谱官方叙事的落点:GLM-5.3 = 5.2 同基座 + 后训练,增益方向是**agentic 协作**(何时该调工具、如何自检),而非纸面心算。官方基准的 DeepSWE +20.7、Terminal-Bench 3.0 4.6→28.3 都是 agent 壳内测的,与本题观察同构。**没有 agent 环境,5.3 对 5.2 的优势很难显现**;反之,给 5.2 一个纯推理任务,它的深思考反而更稳。

### 题 5:长上下文精细度上 5.2 反超(超出预期)

5.2 不仅列出 4 个依赖(ajv/parse5/saxes/simple-icons),还读出了**版本约束的语义差异**:simple-icons 精确锁定 16.28.0(无 `^`),且是唯一"内容生成阶段"依赖,升级会破坏 digest-pinned brand 对象与 canonical zip 字节一致性--这个论证链完整引用了 SKILL.md/DESIGN.md/CONTRIBUTING.md 三处契约。5.3 侧只到文件级定位。** caveat**:5.3 侧此题上下文更大(9.8 万 vs 5.3 万 token),且 5.2 被截断未完成第 3 问,不构成严格意义上的"5.2 更强",但"精细读出版本锁定语义"这一点是硬差距。

### 题 4:CVSS 定级分野

两代都 8/8 命中(含 os.time 笔误、secrets 导入未用细节)。差异在定级:5.2 给弱令牌 9.8 Critical(MD5+时间种子+截断,预认证可枚举,合理);5.3 给 7.5(保守)。5.2 的报告形态也更接近专业渗透测试交付物(含 CWE 编号引用)。

## 五、与 v1(Hy4 官方数据)的合并结论

1. **"后训练决定论"的双重证据**:v1 显示 Hy4 与 GLM-5.3 骨架同构、能力剖面不同;v2 显示 GLM-5.3 与 GLM-5.2 同基座、增益集中在 agent 协作。两组合并:**2026 年开源旗舰的竞争力差异,主要不在架构,而在后训练路线与使用场景的匹配**。
2. **选型落地**(软件研发/人工智能方向):
   - 纯推理/纸面分析场景:5.2 够用且免费通道可跑,深思考更稳
   - agent/工具编排场景:5.3 的增益才兑现,值回票价
   - Hy4:批量 SWE+成本敏感场景(官方基准领先+价格便宜 40%),但实测通道暂时受限
3. **给内容选题的落点**:原选题《Hy4 vs GLM-5.3》保留 v1 官方数据版;v2 实测数据可以独立成篇《同基座两代对决:GLM-5.3 的提升到底在哪》--探针题的"手算出错但工具纠对"是现成的故事钩子。
